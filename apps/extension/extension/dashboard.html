Kết nối TrọCheck

Tạo token trong trang Tài khoản trên web TrọCheck. Bài chỉ được gửi khi bạn bấm nút gửi, và số điện thoại đã được che.

Cài đặt và API key lưu trong trình duyệt này. Bước lọc dùng TypeSafe Jev, bước trích xuất dùng Ollama Cloud.

Prompts

Sửa câu hỏi Jev và hướng dẫn trích xuất bên dưới. Các trường JSON bắt buộc được thêm tự động.

Jev questions are answered independently. Probabilities above 0.6 count as yes, below 0.4 as no; 0.4 through 0.6 are uncertain. Listing count uses Jev’s selected option; unknown remains uncertain.
